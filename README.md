# Housing Price Prediction

This project trains and compares Linear Regression, Decision Tree, and Random Forest models using the California housing dataset in `housing.csv`. It creates a stratified train/test split, preprocesses numerical and categorical features, prints training-set error metrics, and evaluates the Decision Tree with 10-fold cross-validation.

## Requirements

- Python 3.8 or newer
- Packages listed in `requirements.txt`

Install the dependencies with:

```bash
python -m pip install -r requirements.txt
```

## Run the notebook

Keep `housing.csv` in the same folder as `main.ipynb`, open the notebook in Jupyter or VS Code, select a Python environment with the requirements installed, and run the cells from top to bottom.

The original script, `main.py`, is also retained in the project folder.
